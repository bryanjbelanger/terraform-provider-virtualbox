# virtualbox_shared_folder (Resource)

Manages an Oracle VirtualBox shared folder, which exposes a directory on the host to a guest virtual machine. Managed with `VBoxManage sharedfolder`. The VirtualBox Guest Additions must be installed in the guest for the folder to be mounted.

## Example Usage

### Writable, auto-mounted shared folder

```terraform
# A writable shared folder, auto-mounted in the guest (requires Guest Additions).
resource "virtualbox_shared_folder" "data" {
  vm_name   = virtualbox_vm.web.name
  name      = "data"
  host_path = "/srv/data"
  writable  = true
  automount = true
}
```

### Read-only shared folder

```terraform
# A read-only shared folder, auto-mounted in the guest (requires Guest Additions).
resource "virtualbox_shared_folder" "config" {
  vm_name   = virtualbox_vm.web.name
  name      = "config"
  host_path = "/srv/config"
  writable  = false
  automount = true
}
```

## Schema

### Required

- `host_path` (String) Absolute path to the directory on the host that is shared with the guest.
- `name` (String) Name of the shared folder as it appears inside the guest. Changing this forces a new shared folder to be created.
- `vm_name` (String) Name of the virtual machine the shared folder is attached to. Changing this forces a new shared folder to be created.

### Optional

- `automount` (Boolean) Whether VirtualBox automatically mounts the shared folder inside the guest. Requires Guest Additions. Defaults to `false`.
- `writable` (Boolean) Whether the guest can write to the shared folder. When `false`, the folder is mounted read-only. Defaults to `true`.

## Notes

- The guest must have the VirtualBox Guest Additions installed for the shared
  folder to be mounted.
- `showvminfo` does not report the writable or automount flags, so the provider
  tracks them from configuration rather than refreshing them from VirtualBox.

## Import

Shared folders use a composite identifier of the form `vm_name/folder_name`:

```shell
# Shared folders are imported using a composite "vm_name/folder_name" identifier.
terraform import virtualbox_shared_folder.example example-vm/shared
```
