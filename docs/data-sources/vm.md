# virtualbox_vm (Data Source)

Retrieves information about an existing Oracle VirtualBox virtual machine by name, including its hardware allocation, power state, and identifiers.

## Example Usage

```terraform
data "virtualbox_vm" "example" {
  name = "example-vm"
}

output "vm_uuid" {
  value = data.virtualbox_vm.example.uuid
}
```

## Schema

### Required

- `name` (String) Name of the virtual machine to look up.

### Read-Only

- `cpus` (Number) Number of virtual CPU cores assigned to the virtual machine.
- `memory` (Number) Amount of RAM, in megabytes, allocated to the virtual machine.
- `os_type` (String) VirtualBox guest OS type identifier reported for the virtual machine.
- `status` (String) Current power state of the virtual machine, for example `running` or `poweroff`.
- `uuid` (String) Universally unique identifier assigned to the virtual machine by VirtualBox.
- `vram` (Number) Amount of video memory, in megabytes, allocated to the virtual graphics adapter.
